### Pertemuan 3 — Website Promosi Wisata Talaga Nila Majalengka

Website ini merupakan proyek promosi wisata yang bertujuan untuk memperkenalkan keindahan wisata Talaga Nila di Kabupaten Majalengka, Jawa Barat.

Website dirancang dengan tema warna biru yang terinspirasi dari keindahan air dan suasana alam.

### Fitur Website

- **Beranda:** menampilkan halaman utama dan pengenalan wisata.
- **Tentang Wisata:** menjelaskan daya tarik Talaga Nila.
- **Galeri Foto:** menampilkan foto-foto wisata.
- **Aktivitas Wisata:** memberikan informasi mengenai ide aktivitas pengunjung.
- **Biaya Wisata:** menampilkan contoh estimasi biaya dan paket kunjungan.
- **Lokasi Wisata:** menampilkan peta Google Maps dan petunjuk arah.
- **Profil Pembuat:** menampilkan informasi pembuat website, Raihan Alfattah.

### Teknologi yang Digunakan

- HTML untuk struktur halaman.
- CSS untuk desain dan tampilan responsif.
- JavaScript untuk interaksi dan animasi.
- Google Maps untuk informasi lokasi wisata.

### Cara Menjalankan Website

1. Buka folder `tugas pertemuan 3` menggunakan Visual Studio Code.
2. Pastikan file HTML, CSS, JavaScript, dan folder gambar tersedia.
3. Jalankan file `index.html` menggunakan ekstensi Live Server.
4. Website akan terbuka di browser.
